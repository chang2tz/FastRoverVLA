# Links for the manuscript

The public project page is:

[https://adept-org.github.io/FastRoverVLA/](https://adept-org.github.io/FastRoverVLA/)

The public source repository is:

[https://github.com/ADEPT-ORG/FastRoverVLA](https://github.com/ADEPT-ORG/FastRoverVLA)

Use the project-page URL when the paper needs one link covering the method,
paper figures, results and source code. It links directly to the source repository.

Suggested LaTeX text (with `url` or `hyperref` loaded):

```latex
The project page and source code are available at
\url{https://adept-org.github.io/FastRoverVLA/}.
```

For a code-only statement:

```latex
Code is available at \url{https://github.com/ADEPT-ORG/FastRoverVLA}.
```

The project page is deployed from this repository's `main` branch through
GitHub Actions. The URL remains the same when page content is updated.
